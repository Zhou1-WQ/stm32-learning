## 硬件与环境

- 开发板：STM32F103C8T6 最小系统板 ×2（CAN 需要两个节点）
- 下载器：ST-Link V2
- 开发环境：**Keil MDK + 标准库（SPL）**
- 编译器：**ARM Compiler 5（V5.06 update 6）**，勾选 MicroLIB
- 外设：830 面包板、CH340、TJA1050 CAN 收发模块 ×2

> 为什么用标准库而不是 HAL：跟的教程是标准库路线，学的过程能直接看到寄存器操作，对理解外设底层更有帮助。HAL/CubeMX 留到大三做项目时再补。

## 踩坑记录

**1. ST-Link 的接头插不进**
ST-Link V2 引出端是 2×5 双排公针 + 防呆护套，单排 4 孔母座会被护套壁和邻排针卡住。
→ 把连体壳拆成单根母头，一根一根插到底。

**2. 杜邦线配色搞反了**
一开始用「黄=GND、棕=3.3V」，与通行的「红=电源、黑/棕=地」相反。功能能通，但回头看线时极易把红线当电源插到 3.3V 上造成短路。
→ 已改回常规配色：红=3V3、棕=GND、橙=SWCLK、黄=SWDIO。

**3. 新建工程漏配 Define 宏**
报 `error: use of undeclared identifier 'RCC_APB2Periph_GPIOC'`。
→ 魔棒 → C/C++ → Define 填 `USE_STDPERIPH_DRIVER,STM32F10X_MD`，Include Paths 加 `..\Start`、`..\Library`、`..\User`。

**4. 灯亮但不闪**
不是程序没跑，是延时太短：`Delay(500000)` 只有 30–50ms，10 多次/秒的变化人眼会融合成常亮。
→ 延时放大到 `5000000`。**"常亮"和"闪太快"肉眼分不出，先怀疑太快。**

**5. 没有万用表怎么验证接线**
让 Keil 当通断测试仪：Options → Debug → Settings，SW Device 里能读出 `IDCODE 0x1BA01477`，就说明 SWCLK/SWDIO/GND/3.3V 四根线全对。

**6. `warning: last line of file ends without a newline`**
C 标准要求源文件以换行结束，文件末尾敲个回车即可。
