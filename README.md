## 遇到的坑（持续更新）

1. **串口打印乱码**：CubeMX 里晶振频率填成了内部 RC 的 8MHz，实际板子是 8MHz 外部晶振，倍频后主频不对 → 波特率全错。
2. **ST-Link 下载失败**：BOOT0 没接地，改成 Connect under reset 后正常。
3. **定时器不进中断**：忘了在 NVIC 里使能中断，且中断标志位没清。
