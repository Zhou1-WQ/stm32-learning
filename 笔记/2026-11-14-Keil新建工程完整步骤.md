# Keil 新建标准库工程

STM32F103C8T6　Keil MDK5 + SPL + AC5

**一句话：从空文件夹到灯闪，六步——建工程、加文件、配魔棒、写 main、编译、下载。**

> 这篇是**操作手册**，不是实验笔记。用的时候照着表走，别背。

## 一、目录结构

```
工程根目录/
├── Start/      启动文件 + 内核（startup_stm32f10x_md.s、system、core_cm3）
├── Library/    标准外设库
├── User/       main.c、conf.h、it.c
└── Project/    .uvprojx 工程文件
```

## 二、新建工程

1. `Project` → `New μVision Project` → 保存到 `Project/` 目录
2. 选器件：`STMicroelectronics` → `STM32F103` → `STM32F103C8`
3. 弹窗问是否复制启动文件 → **选否**（自己加，避免路径混乱）

## 三、添加文件（Manage Project Items）

| 组 | 加哪些文件 |
|---|---|
| **Start** | `startup_stm32f10x_md.s`、`system_stm32f10x.c`、`core_cm3.c` |
| **Library** | `stm32f10x_rcc.c`、`stm32f10x_gpio.c`、`misc.c`（用哪个加哪个） |
| **User** | `main.c`、`stm32f10x_conf.h`、`stm32f10x_it.c` |

> ⚠️ **Start 组只加 `_md.s` 一个启动文件**。ld / hd / xl 全加会报 `multiply defined`。

## 四、魔棒配置（Options for Target）

| 页签 | 设置项 | 填什么 |
|---|---|---|
| Target | Use MicroLIB | ✅ 勾选 |
| C/C++ | Define | `USE_STDPERIPH_DRIVER,STM32F10X_MD` |
| C/C++ | Include Paths | `..\Start`、`..\Library`、`..\User` |
| Debug | 调试器 | 下拉选 `ST-Link Debugger` → Settings → Port 选 `SW` |
| Utilities | Flash Download | ✅ Reset and Run、✅ Erase Sectors |

> 这些配置**每个新工程都要重配一遍**，Keil 不记忆，模板工程除外。

## 五、点灯代码

```c
#include "stm32f10x.h"

void Delay(uint32_t t) { while (t--); }

int main(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOC, ENABLE);

    GPIO_InitStructure.GPIO_Pin   = GPIO_Pin_13;
    GPIO_InitStructure.GPIO_Mode  = GPIO_Mode_Out_PP;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOC, &GPIO_InitStructure);

    while (1)
    {
        GPIO_ResetBits(GPIOC, GPIO_Pin_13);   /* 低电平点亮 */
        Delay(5000000);
        GPIO_SetBits(GPIOC, GPIO_Pin_13);     /* 高电平熄灭 */
        Delay(5000000);
    }
}
```

## 六、编译下载

| 步骤 | 操作 | 成功标志 |
|---|---|---|
| 编译 | `F7` | Build Output 显示 `0 Error` |
| 下载 | `F8` | `Programming Done` / `Verify OK` / `Application running` |
| 验收 | 看板子 | PC13 LED 闪烁 |

## 七、报错对照表

| 报错信息 | 原因 | 解决 |
|---|---|---|
| `undeclared identifier 'RCC_APB2Periph_GPIOC'` | 漏填 Define 宏 | C/C++ → Define 填 `USE_STDPERIPH_DRIVER,STM32F10X_MD` |
| `cannot open source input file "stm32f10x.h"` | Include Paths 没配 | 加 `..\Start`、`..\Library`、`..\User` |
| `multiply defined` | Start 组加了多个启动文件 | 只留 `startup_stm32f10x_md.s` |
| 下载成功但灯不闪 | 没勾 Reset and Run / 延时太短 | 勾上；`Delay` 改 `5000000` |
