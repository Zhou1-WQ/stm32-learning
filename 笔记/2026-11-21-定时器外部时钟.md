# 6-2 定时器外部时钟

**一句话：把定时器的时钟源从芯片内部换成 PA0 引脚，按键按 3 下累计 3 个脉冲，进一次中断翻转 LED。**

## 关键数

```
ARR  3-1   数满 3 个脉冲进一次中断
PSC  1-1   脉冲直接进计数器，不再分频
```

这节**不写 72MHz**：时钟不是芯片给的，是 PA0 上一个脉冲一个数。

## 卡在哪

按键接 GND，GPIO 配成下拉（IPD）→ 引脚本来就是低，按下还是低 → 永远没有边沿，一次都不计数，也不报错。
解决：改成上拉 `GPIO_Mode_IPU`。

## 记住三条

1. PA0 是 TIM2 的 ETR 引脚，外部时钟只能从这个脚进来
2. **灯不按就不动，说明配对了**；如果它自己闪，反而是内部时钟没换掉
3. 极性决定“按下算”还是“松手算”：`Inverted` 下降沿＝按下，`NonInverted` 上升沿＝松手

## 现象

按 3 下，LED 翻转一次；不动按键，灯一直不动。

---

<details>
<summary>备查：完整代码</summary>

```c
void Timer_Init(void)
{
	RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM2, ENABLE);
	RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);

	GPIO_InitTypeDef GPIO_InitStructure;
	GPIO_InitStructure.GPIO_Mode  = GPIO_Mode_IPU;      //上拉，按键接GND
	GPIO_InitStructure.GPIO_Pin   = GPIO_Pin_0;
	GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
	GPIO_Init(GPIOA, &GPIO_InitStructure);

	//外部时钟模式2：ETR(PA0)驱动计数器
	TIM_ETRClockMode2Config(TIM2, TIM_ExtTRGPSC_OFF,
	                        TIM_ExtTRGPolarity_Inverted, 0x00);

	TIM_TimeBaseInitTypeDef TIM_TimeBaseInitStructure;
	TIM_TimeBaseInitStructure.TIM_ClockDivision     = TIM_CKD_DIV1;
	TIM_TimeBaseInitStructure.TIM_CounterMode       = TIM_CounterMode_Up;
	TIM_TimeBaseInitStructure.TIM_Period            = 3 - 1;
	TIM_TimeBaseInitStructure.TIM_Prescaler         = 1 - 1;
	TIM_TimeBaseInitStructure.TIM_RepetitionCounter = 0;
	TIM_TimeBaseInit(TIM2, &TIM_TimeBaseInitStructure);

	TIM_ClearFlag(TIM2, TIM_FLAG_Update);
	TIM_ITConfig(TIM2, TIM_IT_Update, ENABLE);

	NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2);
	NVIC_InitTypeDef NVIC_InitStructure;
	NVIC_InitStructure.NVIC_IRQChannel                   = TIM2_IRQn;
	NVIC_InitStructure.NVIC_IRQChannelCmd                = ENABLE;
	NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 2;
	NVIC_InitStructure.NVIC_IRQChannelSubPriority        = 1;
	NVIC_Init(&NVIC_InitStructure);

	TIM_Cmd(TIM2, ENABLE);
}
```

中断函数和 6-1 完全一样，只翻转 LED。

</details>

<details>
<summary>备查：坑表</summary>

| 现象 | 原因 | 解决 |
|---|---|---|
| 完全不计数 | 按键接 GND 却配 IPD | 改 `GPIO_Mode_IPU` |
| 一次按键加两次 | 顺手开了 `EXTI_Line0` | 只用 ETR，别开 EXTI |
| 按一下跳好几个数 | 机械抖动 | 正常，加消抖才能根治 |
| 灯自己会闪 | 还留着 `TIM_InternalClockConfig` | 换成 `TIM_ETRClockMode2Config` |

</details>

<details>
<summary>备查：和 6-1 的区别</summary>

| | 6-1 内部时钟 | 6-2 外部时钟 |
|---|---|---|
| 时钟源 | 芯片 72MHz | PA0 引脚脉冲 |
| 不操作时 | 自己闪 | 完全不动 |
| PSC 作用 | 把 72MHz 分到 1 万次/秒 | 1-1 不分频 |
| 关键词 | `TIM_InternalClockConfig` | `TIM_ETRClockMode2Config` |

</details>
