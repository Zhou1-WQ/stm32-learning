# 5-2 按键 + EXTI 模拟对射传感器计次

**一句话：按一下键＝遮挡一次＝来一个下降沿，中断里翻一次灯记一次。**

## 关键数

```
触发方式：EXTI_Trigger_Falling（下降沿）
按键一脚接 PB1，另一脚接 GND，GPIO 配 IPU
```

## 卡在哪

按一次亮，**第二次起就不对** → 中断里写了 `LED_Init()`，每次进中断都把灯复位成初始态 → 初始化只放 main 开头，中断里只翻转。

## 记住三条

1. 初始化＝上电做一次（放 main）；中断＝事件来了做一次，**只干最小的活**
2. **中断里绝不能延时**：Delay 靠 SysTick 推进，而 SysTick 被 EXTI 挡在外面 → 死循环卡死
3. 用**单边沿**：双边沿会按下翻一次、松开又翻一次，等于没翻

## 现象

按一下键，LED 亮灭翻转一次。

---

<details>
<summary>备查：为什么按键能替代传感器</summary>

| | 对射传感器 | 按键替代 |
|---|---|---|
| 接在哪 | PB1 | PB1（同一引脚） |
| 信号来源 | 遮挡 → 输出低电平 | 按下 → 接地低电平 |
| STM32 看到的 | 下降沿 | 下降沿 |
| 记一次 | 遮挡一次 | 按一下 |

没按下=高，按下=低，下降沿触发 → **按下那一刻**记一次。

</details>

<details>
<summary>备查：核心中断函数</summary>

```c
void EXTI1_IRQHandler(void)
{
    if (EXTI_GetITStatus(EXTI_Line1) == SET)
    {
        LED_Turn();                            /* 记一次 → 灯翻转 */
        EXTI_ClearITPendingBit(EXTI_Line1);    /* 必须清标志 */
    }
}
```

</details>

<details>
<summary>备查：CountSensor_Init 完整代码</summary>

```c
void CountSensor_Init(void)
{
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOB, ENABLE);
    RCC_APB2PeriphClockCmd(RCC_APB2Periph_AFIO, ENABLE);

    GPIO_InitTypeDef GPIO_InitStructure;
    GPIO_InitStructure.GPIO_Mode  = GPIO_Mode_IPU;        /* 上拉输入 */
    GPIO_InitStructure.GPIO_Pin   = GPIO_Pin_1;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
    GPIO_Init(GPIOB, &GPIO_InitStructure);

    GPIO_EXTILineConfig(GPIO_PortSourceGPIOB, GPIO_PinSource1);  /* AFIO 选线 */

    EXTI_InitTypeDef EXTI_InitStructure;
    EXTI_InitStructure.EXTI_Line    = EXTI_Line1;
    EXTI_InitStructure.EXTI_LineCmd = ENABLE;
    EXTI_InitStructure.EXTI_Mode    = EXTI_Mode_Interrupt;
    EXTI_InitStructure.EXTI_Trigger = EXTI_Trigger_Falling;
    EXTI_Init(&EXTI_InitStructure);

    NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2);
    NVIC_InitTypeDef NVIC_InitStructure;
    NVIC_InitStructure.NVIC_IRQChannel                   = EXTI1_IRQn;
    NVIC_InitStructure.NVIC_IRQChannelCmd                = ENABLE;
    NVIC_InitStructure.NVIC_IRQChannelPreemptionPriority = 1;
    NVIC_InitStructure.NVIC_IRQChannelSubPriority        = 1;
    NVIC_Init(&NVIC_InitStructure);
}
```

步骤：GPIO 上拉 → 开 AFIO 时钟 + 选线 → 配 EXTI 触发沿 → 配 NVIC → 写中断函数。

</details>

<details>
<summary>备查：全部坑表</summary>

| 现象 | 原因 | 解决 |
|---|---|---|
| 按一次亮，第二次起不对 | `LED_Init()` 写在中断里 | 初始化只放 main |
| 按键没反应 | 选了双边沿，翻两次等于没翻 | 用单边沿 |
| 中断里 `Delay_ms(20)` 卡死 | SysTick 被挡在中断外，计数不走 | 中断里绝不延时 |
| 优先级都填 1 为什么 | 分组 2 拆成 2+2 位，各能填 0~3；只有一个中断填几都一样 | 照抄 1，0 留给以后更急的中断 |
| 中断函数不执行 | 函数名和向量表对不上 | 逐字核对 `EXTI1_IRQHandler` |

**为什么中断里不能延时**：CPU 在跑 EXTI 中断时 SysTick 进不来 → `Delay_ms()` 里等计数的 while 永远等不到。正确做法：中断里只置 `Key_Flag = 1`，main 里判断。

</details>
