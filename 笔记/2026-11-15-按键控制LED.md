
# 3-4按键控制 LED

## 这次做了什么

点灯和读按键各封装成驱动文件，main 只调度：按一下键，LED 翻转一次。

## 工程结构

```
User/main.c        主逻辑（只有调度）
Hardware/LED.c/h   LED 驱动
Hardware/Key.c/h   按键驱动
```


## 按键消抖

```c
if (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_1) == 0)   /* 按下=低电平 */
{
    Delay_ms(20);                                          /* 消抖 */
    while (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_1) == 0); /* 等松手 */
    Delay_ms(20);
    return 1;
}
```

- 按下先等 20ms：跳过机械抖动
- `while(...==0);` 空语句卡住：**松手才返回**，一次按下只算一次
- 按键初始化用 `GPIO_Mode_IPU`（上拉输入）

## main 只写业务

```c
LED_Init();
Key_Init();

while (1)
{
    KeyNum = Key_GetNum();
    if (KeyNum == 1) LED1_Turn();
}
```

`LED1_Turn()` 内部用 `GPIO_ReadOutputDataBit` 读 ODR 再取反——**读的是输出状态，不是输入**。

## 现象

- 按一下 LED 亮灭翻转一次

## 踩坑

**现象**：按住不放，LED 一直闪。

**原因**：`while (...);` 漏了 `== 0`。漏了之后条件变成"按下时成立"，按下就立刻退出，一直按就一直返回 1、一直翻转。

**正确**：`while (... == 0);` —— 按着不走，松手才走。

## 为什么要模块化

| 好处 | 体现 |
|---|---|
| 换引脚只改一处 | PA1 换 PB0 只动 LED.c |
| main 只写业务 | main 里没有寄存器操作 |
| 团队协作 | 接口在 .h 说清楚，各写各的 .c |

这就是驱动层 + 应用层的雏形，VCU/BMS 代码都这么组织。
