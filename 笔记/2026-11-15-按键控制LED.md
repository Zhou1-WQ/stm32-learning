# 3-4 按键控制 LED

**一句话：把点灯和读键各封成一个驱动，main 只写“按一下就翻灯”这一句业务。**

## 关键数

```
消抖：按下等 20ms → 等松手 → 再等 20ms
```

## 卡在哪

按住不放灯狂闪 → `while (...);` 漏了 `== 0`，条件变成“按下时成立”，主循环反复返回 1 → 补上 `while (... == 0);`。

## 记住三条

1. `while (...==0);` 是“按着不走，松手才走”；漏掉 `==0` 就成了“越按越走”
2. `LED_Turn()` 用 `GPIO_ReadOutputDataBit` 读 **ODR**——读的是输出状态，不是输入
3. 按键初始化用 `GPIO_Mode_IPU`（上拉输入，按键接 GND）

## 现象

按一下，LED 亮灭翻转一次。

<details>
<summary>备查：工程结构与消抖代码</summary>

```
User/main.c        主逻辑（只有调度）
Hardware/LED.c/h   LED 驱动
Hardware/Key.c/h   按键驱动
```

```c
if (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_1) == 0)      /* 按下=低电平 */
{
    Delay_ms(20);                                        /* 跳过抖动 */
    while (GPIO_ReadInputDataBit(GPIOB, GPIO_Pin_1) == 0);/* 等松手 */
    Delay_ms(20);
    return 1;
}
```

```c
LED_Init();
Key_Init();

while (1)
{
    KeyNum = Key_GetNum();
    if (KeyNum == 1) LED_Turn();
}
```
