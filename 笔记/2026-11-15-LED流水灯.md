# 3-3 流水灯

**一句话：8 个 LED 依次点亮——循环移位 + `GPIO_Write` 整口写，不用一个个 `SetBits`。**

## 关键数

```
8 个灯，Delay_ms(200) → 一个循环 1.6 秒
```

## 卡在哪

没踩坑。

## 记住三条

1. `GPIO_Write(GPIOA, 值)` 一次写整个 16 位端口，比逐脚 `SetBits` 干净
2. 要**取反** `~`：因为是低电平点亮，写 0 的那个脚才亮
3. 数组法和移位法等价，**移位法不用维护数组**，推荐

## 现象

PA0~PA7 依次亮，转一圈再来。

---

<details>
<summary>备查：完整代码</summary>

接线：推挽输出，8 个 LED 长端接正极，短端分别接 PA0~PA7。

```c
uint16_t PA[8] = {0x0001, 0x0002, 0x0004, 0x0008, 0x0010, 0x0020, 0x0040, 0x0080};

while (1)
{
	for (int i = 0; i < 8; i++)      /* 数组法 */
	{
		GPIO_Write(GPIOA, ~(PA[i]));
		Delay_ms(200);
	}

	for (int i = 0; i < 8; i++)      /* 移位法 */
	{
		GPIO_Write(GPIOA, ~(GPIO_Pin_0 << i));
		Delay_ms(500);
	}
}
```

`GPIO_Pin_0 << i` 就是让 1 逐位左移：0x0001 → 0x0002 → 0x0004 …… 取反后对应脚变低，灯亮。

</details>
