# 2026-11-14　环境搭建与 ST-Link 接线

## 硬件

| 线色 | 板子 | ST-Link（2×5 双排） |
|---|---|---|
| 红 | `3V3` | ⑦ / ⑧ |
| 棕 | `GND` | ⑤ / ⑥ |
| 橙 | `SWCLK` | ② |
| 黄 | `SWD` | ④ |

- 上排奇数 ①③⑤⑦⑨　下排偶数 ②④⑥⑧⑩
- **⑨⑩ 是 5.0V，禁接**
- ①（RST）、③（SWIM）不用

> 4 孔连体母座插不进护套，须拆成单根，一根一根插到底。

## 软件

| 项 | 设置 |
|---|---|
| 编译器 | AC5（`V5.06 update 6`），选 `Use default compiler version 5` |
| MicroLIB | ✅ 勾选 |
| Pack | `Keil::STM32F1xx_DFP` |
| Define | `USE_STDPERIPH_DRIVER,STM32F10X_MD` |

> AC5 vs AC6：跟标准库教程走 AC5。AC6 编译快，但老工程会冒一堆警告，新手分不清是代码问题还是编译器问题。

## 验证接线的两个办法

**有 Keil**：`Debug` → `Settings`，SW Device 出现 `IDCODE 0x1BA01477` = 四线全对

**有万用表**：蜂鸣档测 `板3V3 ↔ ⑦`、`板GND ↔ ⑤`，都响即通

## 三个坑

**1. 灯亮但不闪**
`Delay(500000)` 在 72MHz 下只有 30–50ms，10–16Hz 的变化人眼会融合成常亮。
→ 改 `Delay(5000000)`。**"常亮"和"闪太快"肉眼分不出，先怀疑太快。**

**2. 漏 Define 宏**
报 `undeclared identifier 'RCC_APB2Periph_GPIOC'`。
→ 魔棒 → C/C++ → Define 填 `USE_STDPERIPH_DRIVER,STM32F10X_MD`。

**3. 文件末尾无换行**
`warning: last line of file ends without a newline` → 末尾敲个回车。
