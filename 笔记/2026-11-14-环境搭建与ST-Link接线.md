# 环境搭建与 ST-Link 接线

STM32F103C8T6　Keil MDK5 + SPL + AC5

**一句话：4 根线接 ST-Link、装 AC5 编译器，能读出 IDCODE 就算通了。**

> 这篇是**操作手册**。换电脑、换板子、接线忘了颜色时回来查。

## 一、接线（4 根线）

| 线色 | 板子引脚 | ST-Link 引脚 |
|---|---|---|
| 红 | `3V3` | ⑦ 或 ⑧ |
| 棕 | `GND` | ⑤ 或 ⑥ |
| 橙 | `SWCLK` | ② |
| 黄 | `SWDIO` | ④ |

**2×5 排针编号口诀**：上排奇数 ①③⑤⑦⑨，下排偶数 ②④⑥⑧⑩

| 编号 | 功能 | 用不用 |
|---|---|---|
| ①③ | RST / SWIM | 不用 |
| **⑨⑩** | **5.0V** | **禁接，会烧板** |
| ②④⑤⑥⑦⑧ | SWCLK / SWDIO / GND / 3V3 | 用 |

> 4 孔连体母座插不进防呆护套，必须拆成单根，一根一根斜着插到底。

## 二、软件配置

| 项 | 设置 |
|---|---|
| 编译器 | `AC5 (V5.06 update 6)` → 选 Use default compiler version 5 |
| Pack | `Keil::STM32F1xx_DFP` |
| MicroLIB | ✅ 勾选 |
| Define | `USE_STDPERIPH_DRIVER,STM32F10X_MD` |

> **为什么用 AC5**：标准库是 AC5 时代的产物。AC6 编译快，但老工程会冒一堆警告，新手分不清是代码错还是编译器错。

## 三、验证接线（二选一）

| 方法 | 操作 | 判定通过 |
|---|---|---|
| 有 Keil（推荐） | Debug → Settings | SW Device 显示 `IDCODE 0x1BA01477` |
| 有万用表 | 蜂鸣档测 板3V3↔⑦、板GND↔⑤ | 两处都响 |

`0x1BA01477` 是 STM32F103 的 SW-DP 签名，能读出来说明 SWCLK、SWDIO、GND、3V3 四根线全通。

## 四、三个坑

| # | 现象 | 原因 | 解法 |
|---|---|---|---|
| 1 | 灯亮但不闪 | `Delay(500000)`@72MHz ≈ 30–50ms，10–16Hz 人眼融合成常亮 | 改 `Delay(5000000)`。**常亮和闪太快肉眼分不出，先怀疑太快** |
| 2 | 报 `undeclared identifier 'RCC_APB2Periph_GPIOC'` | Define 宏没填 | 魔棒 → C/C++ → 填 `USE_STDPERIPH_DRIVER,STM32F10X_MD` |
| 3 | 报 `last line of file ends without a newline` | 文件末尾没换行 | 末尾敲个回车 |
