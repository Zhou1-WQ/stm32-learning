# GPIO 输出实战（点灯与流水灯）

**一句话：推挽输出 + Delay，让一个灯亮灭交替，让八个灯轮流亮。**

## 关键数

```
闪烁：Delay_ms(500) × 2  → 一个完整周期 1 秒
流水灯：8 个灯 × Delay_ms(200) → 转一圈 1.6 秒
```

## 卡在哪

灯不亮 → LED 正负极接反或忘了串电阻 → 长端（正）接电源、短端接 PA0。

## 记住三条

1. 推挽输出**低电平点亮**；开漏输出**只能**低电平点亮
2. 三种改电平写法完全等价：`ResetBits/SetBits`、`WriteBit(...Bit_RESET)`、`WriteBit(...(BitAction)0)`
3. 整口写用 `GPIO_Write(GPIOA, ~(GPIO_Pin_0 << i))`，取反是因为低电平才亮

## 现象

单个灯 1 秒一闪；PA0~PA7 依次亮、转一圈再来。

---

<details>
<summary>备查：LED 三种接法</summary>

| 模式 | 点亮方式 | 怎么接 |
|---|---|---|
| 推挽（PP） | 低电平点亮 | LED 长端接正极，短端接 PA0 |
| 推挽（PP） | 高电平点亮 | LED 长端接 PA0，短端接负极 |
| 开漏（OD） | 只能低电平点亮 | LED 长端接正极，短端接 PA0 |

</details>

<details>
<summary>备查：闪烁代码</summary>

```c
while (1)
{
	GPIO_ResetBits(GPIOA, GPIO_Pin_0);
	Delay_ms(500);
	GPIO_SetBits(GPIOA, GPIO_Pin_0);
	Delay_ms(500);

	GPIO_WriteBit(GPIOA, GPIO_Pin_0, Bit_RESET);
	Delay_ms(500);
	GPIO_WriteBit(GPIOA, GPIO_Pin_0, Bit_SET);
	Delay_ms(500);

	GPIO_WriteBit(GPIOA, GPIO_Pin_0, (BitAction)0);
	Delay_ms(500);
	GPIO_WriteBit(GPIOA, GPIO_Pin_0, (BitAction)1);
	Delay_ms(500);
}
```

三段写法效果一样，只是换了个函数。

</details>

<details>
<summary>备查：流水灯代码</summary>

接线：推挽输出，8 个 LED 长端接正极，短端分别接 PA0~PA7。

```c
uint16_t PA[8] = {0x0001, 0x0002, 0x0004, 0x0008, 0x0010, 0x0020, 0x0040, 0x0080};

while (1)
{
	for (int i = 0; i < 8; i++)      /* 数组法 */
	{
		GPIO_Write(GPIOA, ~(PA[i]));
		Delay_ms(200);
	}

	for (int i = 0; i < 8; i++)      /* 移位法，不用维护数组 */
	{
		GPIO_Write(GPIOA, ~(GPIO_Pin_0 << i));
		Delay_ms(500);
	}
}
```

`GPIO_Pin_0 << i` 让 1 逐位左移：0x0001 → 0x0002 → 0x0004 …… 取反后对应脚变低，灯亮。

</details>
