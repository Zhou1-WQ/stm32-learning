# 笔记怎么写

## 一句话

**只写三样：做了什么、卡在哪、怎么解决的。**

其他都可以不写。

## 模板

新建 `笔记/YYYY-MM-DD-主题.md`：

```markdown
# 2026-11-20　定时器中断

## 做了什么

- 用 TIM2 做 1 秒中断，中断里翻转 PC13

## 卡在哪

- 中断进不去，灯不闪

## 怎么解决

- 忘了 `TIM_ITConfig(TIM2, TIM_IT_Update, ENABLE)`
- 还忘了在 `stm32f10x_it.c` 里写 `TIM2_IRQHandler`
```

就这些。三五行也算一篇。

## 什么不用写

| 不用写 | 原因 |
|---|---|
| 大段原理讲解 | 教程里有，抄一遍等于没学 |
| 代码全文 | 代码在工程里，笔记里只贴关键几行 |
| 心得体会、感想 | 写的时候很累，回头看没人读 |
| 你还没做的事 | 只写做过的，计划放脑子里或待办清单 |

## 什么时候写

**做完一个实验，趁着还记得，五分钟写完。** 隔一天就忘一半。

## 三种更省事的写法

**1. 只写坑**
没坑就只写一行"今天跑通了串口，没什么问题"。这不是偷懒，是如实记录。

**2. 截图代替描述**
报错截图扔进笔记文件夹，笔记里 `![](./img/报错.png)`。比打字描述快得多。

**3. 口头记，我帮你整理**
你跟我说一句"今天卡在中断进不去，原因是忘了开 TIM_ITConfig"，我照着模板补成笔记，你确认后提交。

## 目录约定

```
笔记/
├── 2026-11-14-环境搭建与ST-Link接线.md
├── 2026-11-20-定时器中断.md
├── 2026-11-27-串口与printf重定向.md
└── img/                    截图放这里
```

日期在前，按文件名排序就是时间线。
